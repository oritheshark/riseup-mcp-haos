# RiseUp MCP – Home Assistant add-on

Home Assistant OS add-on that runs the official [RiseUp MCP server](https://github.com/riseup-oss/mcp)
and exposes it as an OAuth-protected remote MCP connector for Claude, including the mobile app.

Install it from **Settings → Add-ons → Add-on Store → ⋮ → Repositories** by adding this repository's URL.
Setup instructions are in [riseup_mcp/DOCS.md](riseup_mcp/DOCS.md).
